# 阶段 0：负载模型与 SLO 基线

**状态**：用户确认的新设计压力目标已记录；实际日交易台账/请求结构和生产 SLO 待补
**适用范围**：先用于本地/16 GB 开发服务器的可复测容量测试，不代表生产容量承诺

| 日交易量 | 未提供；旧约 16,000 笔/日输入已作废 | 当前实际日量待上线台账或试点数据，不以新压力目标反推 |

按用户要求，阶段文档不填写个人或部门责任方。3,200 笔/分钟及 96,000 笔/30 分钟作为开发容量压力目标记录；它是新设计输入而非历史实测，实际日内分布仍须由台账或试点数据校准，因此不据此宣称已建立生产业务曲线或生产 SLO。

## 2. 开发验证档位

| 场景 | 目标输入 | 用途 | 通过/报告口径 |
|---|---:|---|---|
| 单站点峰值 | 800 笔/分钟（约 13.3 笔/秒），持续 30 分钟 | 单站点容量目标 | 记录滚动窗口完成量、错误、延迟分位数和资源；业务 API 实现后执行 |
| 全平台峰值 | 3,200 笔/分钟（约 53.3 笔/秒），4 站点并发，持续 30 分钟 | 全平台容量压力目标；总量 96,000 笔 | 按站点分配请求并分别统计；实际业务曲线仍须台账校准 |
| 交易类型 | 消费 ≥90%；充值/补助 ≤8%；退款/冲正 <2% | 请求类型覆盖目标 | 实施负载模型时明确余量类别、各类型 payload、账户分布和幂等特征 |
| 交易日批量 | 实际日量待确认 | 后续清结算/日结批次测试输入 | 旧 16,000 笔/日已作废；批次规模、完成时限与日内分布待台账/契约确定 |
| 离线容量 | 每终端脱网记账 ≥100,000 条、白名单 ≥20,000 张；按 800 笔/终端/日可覆盖约 125 天 | 用户指定目标；基础要求覆盖 3 个就餐日；单笔和日累计限额可配置 | 记录厂商规格、断电/WAL/闪存耗尽、恢复补传和限额拒绝；125 天是算术容量比，不是设备实测 |
| 故障与恢复 | 离线消费、重复/乱序补传和服务恢复 | 检查幂等、资金一致性、队列积压与恢复 | 终端型号/协议及恢复时限仍需厂商资料与设备联测 |

完整业务曲线仍需根据台账或试点数据核实实际日交易量、日内分布、交易类型比例、交易 payload、账户倾斜、重试行为和站点到食堂的映射。业务 API 尚未实现；当前 k6 脚本仅测 Actuator 健康，不得用于声称达到上述交易档位。

## 3. 测量项与验收边界

每次本地或服务器测试记录相同环境信息，并至少输出：

- 实际到达率、完成率和每个 1 分钟滚动窗口的最大完成量。
- p50/p95/p99 延迟、超时、连接错误、HTTP 5xx 与业务拒绝；业务拒绝和平台技术错误分开统计。
- 交易/账户账本一致性、幂等重复结果、离线序号缺口、补传队列积压和清空时间。
- CPU、内存、JVM/GC、线程与连接池、数据库锁/慢查询、缓存命中/错误及消息积压。
- 完整命令、代码版本、镜像/依赖版本、测试数据、日志及原始报告。

现阶段不指定生产 p95/p99、错误预算、逐服务资源上限、最大增长规模或 RTO/RPO。若接口实现前先做 stub/平台 PoC，报告只能说明该 PoC 在已记录开发资源上的结果。真实 API 落地后按单站点 800/min 与四站点并发 3,200/min、持续 30 分钟的开发压力档位验证；取得实际台账后再校准实际业务曲线。资金链路必须同时证明无重复入账、无漏失和账户/交易状态可收敛。

仓库 k6 通用模板当前给出错误率低于 1%、关键接口 p95 低于 500 ms、checks 成功率高于 99% 的默认阈值。这些值目前是脚手架约定，不是已批准的交易接口开发 SLO 或生产 SLO；健康端点冒烟结果也不能代替交易链路验收。进入阶段 1 性能门禁前，须按接口类型和业务拒绝语义批准开发环境阈值，并同步更新测试脚本/阶段报告。

1. 本地构建、现有测试和启动验证通过后，才尝试远端开发服务器测试。
2. 当前本地宿主机可见内存约 15.86 GiB。此前一次采样记录瞬时可用内存约 3.75 GiB、Docker VM 上限约 7.68 GiB、运行容器汇总约 3.0 GiB；2026-11-03 盘点时本地 Docker 容器均已停止，本次未启动既有监控栈。以上资源数据是历史采样，后续并发压测前须重新采集宿主机/Docker 可用内存及容器实际占用。
3. 2026-11-03 已通过 SSH 只读盘点开发服务器：Ubuntu 22.04.5 LTS、Linux 6.8 x86_64、8 vCPU、15 GiB 内存（约 14 GiB available）、根盘 503 GiB（约 410 GiB 可用）、OpenJDK 17.0.20.1、Docker 29.6.2。OceanBase/Flyway 临时 PoC 已运行并清理；未部署业务应用 JAR。项目 Maven 基线目标 Java 25，远端 JDK 17 与项目运行目标存在差异，未验证应用运行兼容性。
4. 任何本地或 16 GB 开发服务器结果仅用于开发比较。生产资源更换或目标平台确定后，必须按实测业务负载重新做容量与恢复测试。
